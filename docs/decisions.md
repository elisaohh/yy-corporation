## 브랜드 색 기준 (잠정)

| 팬톤 | 현재 기준 (공식 SVG) | 이전 잠정값 | 차이 | 쓰임 |
|---|---|---|---|---|
| 1225 C | `#FFC844` (로고 심볼) | `#FFC845` | Blue 채널 −1, 육안 차이 없음 | 면 전용 (버튼 호버, 선택 상태) |
| 4008 C | `#F7AF22` (로고 워드마크) | `#F3AF22` | Red 채널 +4, 약간 더 밝은 주황 | 선 전용 (진행선, 오류 표시선) |

- 두 값 모두 흰 바탕 글자색으로는 쓰지 않는다(대비 1.5–1.9 : 1). 차콜 글자를 올리는 면, 2px 이상 선으로만 사용.
- 브랜드 가이드나 원본 색상 데이터가 오면 `src/app/globals.css`의 `--color-point-*` 두 값만 바꾼다.

## 알려진 미구현 / 후속 작업

- 페이지 전환은 현재 진입 페이드만 있다. 떠날 때의 페이드는 모션 단계에서 추가 검토.
- 전역 부드러운 스크롤은 모션 단계에서 GSAP와 함께 적용(현재 네이티브 스크롤).
- 로더는 실제 로딩이 생기는 단계(3D·시퀀스)에서 연결.
- 파비콘: 공식 심볼 단독 파일이 없어 미적용. 로고를 잘라 만들지 않는다.
- `/logo-check`는 내부 검토용 페이지 — 배포 전 삭제.
