# 카페24 웹호스팅에 올리는 방법 (디자인 업체 전달용)

YY CORPORATION 홈페이지는 **완성된 파일 묶음**(HTML · CSS · JS · 사진 · 영상)으로 드립니다.
이 파일을 카페24 웹호스팅에 **그대로 올리면** 기준 사이트(https://yy-corporation.vercel.app)와 **화면 · 모션이 100% 같습니다.**
같은 코드로 만든 같은 파일이기 때문입니다(2026-10-29 기준 페이지별 화면 비교: 차이 0%).

> ⚠ 워드프레스 · 엘리멘터로 **다시 만들지 말아 주세요.** 다시 만들면 글꼴 · 모션 · 간격이 달라집니다(테마 CSS · 테마 모션과 겹침).
> 파일 안의 HTML · CSS · JS도 **직접 고치지 말아 주세요.** 고칠 내용은 저희가 새 파일 묶음으로 다시 드립니다.

---

## 1. 받는 것

`yy-corporation-site-날짜.zip` — 압축을 풀면 아래처럼 생겼습니다.

```
.htaccess          ← 웹서버 설정(숨김 파일 — FTP 프로그램에서 "숨김 파일 보기"를 켜야 보임)
index.html         ← HOME
404.html
about/  products/  process/  contact/  privacy/  terms/   ← 각 페이지
_next/             ← 화면 · 모션 코드(CSS · JS)
assets/            ← 사진 · 영상 · 로고
```

## 2. 올리는 방법

1. **기존 워드프레스 백업** — 카페24 관리 → 호스팅 관리 → 백업, 또는 FTP로 `www` 폴더 전체를 내려받아 보관.
2. 웹 루트(`www` 폴더)에서 워드프레스 파일을 다른 폴더로 옮기거나 지웁니다(특히 워드프레스의 `index.php` · `.htaccess`가 남아 있으면 안 됩니다).
3. zip을 풀어 나온 **내용 전부**를 `www` 폴더 **바로 아래**에 올립니다(`www/index.html`, `www/.htaccess`, `www/_next/…`).
   - **반드시 도메인 맨 앞(루트)** 이어야 합니다. `www/yy/` 같은 하위 폴더에 올리면 사진 · 화면 코드 경로가 맞지 않습니다.
   - `.htaccess`가 꼭 함께 올라갔는지 확인해 주세요(숨김 파일).
4. 도메인(`yycorp.co.kr` 등)을 이 호스팅에 연결합니다.

워드프레스를 꼭 남겨야 한다면, 워드프레스는 다른 주소(예: `wp.yycorp.co.kr`)로 옮기고 홈페이지 주소에는 이 파일 묶음을 올려 주세요.

## 3. 올린 뒤 확인

| 확인 | 기대 결과 |
|---|---|
| `/` | 로딩(로고 → 커튼) 뒤 병 · 물방울이 떠다니는 첫 화면, 스크롤하면 공정 모션(코팅 → 인쇄 → 부식 → 라벨 → 스포이드 체결) |
| `/about` | 자동으로 `/about/company/`로 이동 |
| `/about/story/` | 뉴스레터 카드(사진 · 제목 · 요약), 카드를 누르면 뉴스레터 원문 |
| `/products/` | 종류 탭 · 용량(ml) 버튼으로 걸러 보기, 카드 → 제품 상세(사진 넘기기 · 규격) |
| `/process/` | 제목 배경 영상(유리 성형기)이 반복 재생 |
| `/contact/` | 문의 폼 → 보내기를 누르면 방문자의 메일 앱이 열리고 `sales@yycorp.co.kr` · 제목 · 내용이 채워짐 |
| 없는 주소(예: `/abc`) | 사이트 디자인의 404 화면 |
| 휴대폰 | 오른쪽 위 메뉴(햄버거) 버튼으로 모든 페이지 이동 |

이상하게 보이면 기준 사이트(https://yy-corporation.vercel.app)와 나란히 열어 비교해 주세요. 차이가 있으면 대부분 ① `.htaccess`가 빠졌거나 ② 하위 폴더에 올렸거나 ③ 워드프레스 파일이 남아 있는 경우입니다.

## 4. 이 파일 묶음에 들어 있지 않은 것

| 기능 | 이유 · 대신 |
|---|---|
| 사이트 위 편집(`/admin` 로그인 · 제품 · 뉴스레터 올리기) | 서버가 필요한 기능이라 기준 사이트(Vercel)에서만 동작합니다. 카페24 주소의 `/admin`은 Vercel 편집 화면으로 연결됩니다. |
| 서버에서 보내는 문의 메일 | 지금은 방문자의 메일 앱으로 보내는 방식이라 서버가 필요 없습니다(그대로 동작). |

## 5. 내용이 바뀔 때 (제품 · 뉴스레터 추가 등)

1. YY에서 Vercel 편집 화면(`/admin`)으로 고칩니다 → 기준 사이트에 반영.
2. 새 파일 묶음(zip)을 만들어 업체에 보냅니다(`npm run export`).
3. 업체는 `www` 폴더의 **`_next` 폴더를 지우고** 새 zip 내용을 전부 덮어써 올립니다(다른 파일은 덮어쓰기만 하면 됩니다).

> 나중에 원하면 2~3번을 자동으로(저장하면 카페24에 바로 올라가게) 연결할 수 있습니다. 카페24 FTP 계정 정보를 GitHub 비밀 값으로 넣는 설정이 필요합니다.

## 6. 기술 참고

- 만든 방법: Next.js 16 정적 내보내기(`output: "export"`, `trailingSlash: true`) — `npm run export` (`scripts/export-static.mjs`). 서버 기능(`src/app/api`, `src/app/admin`)은 내보낼 때 빠집니다.
- `.htaccess`: `/about` → `/about/company/`, 예전 뉴스레터 주소 → 새 주소, `/admin` → Vercel 편집 화면, 404 화면, 파일 형식 · 캐시 설정. Apache(카페24 웹호스팅) 기준입니다.
- 검색 노출: 공개 전 단계라 모든 페이지에 검색 차단(noindex)이 들어 있습니다. 정식 공개 때 저희가 풀어서 다시 드립니다.
- 글꼴: Pretendard · Inter 파일이 묶음 안(`_next/static/media`)에 들어 있어 따로 설치할 필요가 없습니다.
